## 实际处理规则

1. 只读现有源的train；保护所有源val的音频、原音频、已知身份、会话及归一化文本。
   当前冻结case与仓库已有评测case文本同样排除，不把验证数据挪回训练。
2. 检查真实16k单声道、3–30秒、时长字段吻合、有限且非全零波形、幅度不越界。
   用解码后PCM哈希排除与验证音频完全相同及候选间重复的录音。
   这是精确去重，不声称识别了重编码、背景变化等近重复。
3. 连续满幅平台≥1ms、近零尾部>0.5s仅作为候选隔离规则，写声学复核清单；
   不声称已确认爆音，也不把它们设成模型验收新门禁。不额外裁切/去噪/重归一化音频。
4. 使用既有 `pair_references` 和 `checked_pairs`：仅可信同人、不同原音频、不同文本，
   ref 3–10秒、split内配对；不改origin，不新造speaker、情绪或控制标签。
5. ref比例1只用来列出可选配对库存，不表示下一轮100%配ref；
   目标曝光、ref复用、实际语言占比仍须在下一轮正式混合时重新统计。
6. 保留文本标点/大小写、原始出处；按源列3–8s/8–15s/15–30s分布。
   不用跨语种不可比的F0、语速或失效UTMOS来宣布数据优质。

CV22 VI仍无可信身份，不配ref；YODAS MS的马来西亚口音仍未验证。
二者只列作单独源实验候选，不因已经存在就悄悄替换当前配方。
本轮不承诺数据清理或更多ref必然改善模型；实际方向需看r10的B对A，以及各语种对r8。
