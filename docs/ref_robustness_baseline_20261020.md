> 冻结口径见 `docs/ref_robustness_plan_20261012.md`（2026-10-19 按三语种修订）。

  干扰池 = `fleurs_{th,tl,id}_tc` **train** 6818 行（split 隔离，与 val 派生 ref 无重叠）；
  sidecar `eval_cases/refs_degraded/degradations.jsonl`（45 条，含实际 SIR/干扰源 origin）。
- 生成：base + r8（`/root/autodl-tmp/voxft_ckpt/lora_omni5_r8/latest`），
  cfg 1.8 / 20 步 / 禁重试 / seeds 42,43,44，共 **648 次生成全部完成**
  （2026-10-20 10:18–11:03，3 分片并行，驱动 `scripts/refrob_stage1_driver.sh`）。
- 代码：speaker_sim 本轮起对**原始干净 ref** 计算（commit `2b1ab8b`，含回归测试，
  本地/远端各 164 通过）。冒烟 2 条件 × 6 生成先行验证通过。
- 报告：12 份合并报告（各 54 条）在远端 `voxft_ckpt/eval/`，
  条件→报告映射 `refrob_20261020/report_map.jsonl`，配对统计 `paired_analysis.json`

## 配对差值（降质 − clean，case 内 3 seed 均值，18 case bootstrap 95% 区间）

**speaker_sim（对原始干净 ref）——最强信号：**

| 条件 | base ΔSIM | r8 ΔSIM |
|---|---|---|
| babble_sir15 | +0.0025 [−0.009,+0.015] | −0.0050 [−0.015,+0.006] |
| babble_sir8 | **−0.0199 [−0.031,−0.009]** | **−0.0281 [−0.039,−0.019]** |
| lowpass4k | **−0.0269 [−0.042,−0.014]** | **−0.0263 [−0.041,−0.013]** |
| lowpass3k | **−0.0401 [−0.058,−0.023]** | **−0.0381 [−0.053,−0.025]** |
| combo | **−0.0398 [−0.054,−0.025]** | **−0.0500 [−0.062,−0.039]** |

4/5 条件两模型均显著（区间不跨零）、随 severity 单调、幅度全面超过 run 间噪声 ±0.009；
中度串音（sir15）确实无感（区间跨零，符合 profile 设计预期）。

**CER**：5/5 条件两模型方向一致为正（+0.010 ~ +0.028），但 n=18 下区间全部跨零或贴零
（最差的 r8/combo +0.0279 [−0.0005,+0.0701]）——**方向一致、功效不足，记为弱信号**，
不作为闸门依据，留作阶段 2/3 改善幅度的对照基线。

**audio_sec（时长）**：串音类条件两模型一致**变短**（base sir8 −0.38s [−0.78,−0.04]、
combo −0.42s [−0.75,−0.12]；r8 combo −0.42s [−0.65,−0.21]）——差参考下模型倾向于少说话，
与 SIM 下降共同构成「脏条件 → 输出退缩」的形态。

**单点坏例**：r8 / lowpass4k / `id_nat_02` / seed42 → 17.92s 音频含 **15.16s 尾静音**
（clean 同条件 2.40s/0.00s），一句话带飞 r8 lp4k 整列尾静音均值（+0.254s、id 分语种
+0.812s）。属降质 ref 诱发的跑飞垫尾实例，正是阶段 2 想压的形态；已留在报告
（`lora_omni5_r8_latest_2dfa3cd35a014cfb91e0fdb70c09d2a7a…` 见 report_map）不删不改。

## 闸门结论：**有可测退化 → 满足进入阶段 2/3 的证据条件**

依据：SIM 在 4/5 降质条件下显著退化且随 severity 单调（两模型同形态）；
CER 方向一致但功效不足；时长退缩显著。「基线无可测退化则停止」的停止条件**未触发**。

## 阶段 2/3 待用户确认（含一处被迫的方案修订）

冻结计划写「基于 r8 同源配比生成训练集」，但 **r8 是五语种配比（含 ms/vi 各 17%），
且 vi/ms 数据本轮已按用户决定从远端删除**——r8 配方已无法原样重建，也不该重建。
建议修订为（其余按冻结计划不变）：

- A 组（对照）/B 组（50% ref 降质）都用**新三语种配比**（th/tl/id 各 28.3 分 +
  zh 10 + en 5，按有效时长），同预算（12h 目标音频、1 epoch、从官方基座新训、
  r=64/alpha=64/dropout 0.05、enable_dit、proj 关、lr 1e-4），唯一变量 = ref 降质；
  r8 作额外参照（它是五语种老配方，不在 A/B 配对内）。

  退化即整轮不通过）+ 降质 6 条件套件看 SIM/时长退缩是否收窄；speaker_sim 全量记录。
- 训练伴随 wandb 桥接进程（连通性已实测通过，项目 liudunxu22-b/voxcpm-finetune）。
