# r10：可信同人 ref 开/关对照

日期：2026-09-17。用户已授权执行；生产 r8 保持不变。

## 假设与范围

用现有 CV22 泰语/印尼语的可信同人跨文件 ref，检查参考条件训练是否改善跨 seed/跨 cue 音色一致性。
不依赖 drama，不生成同源切片，不伪造 speaker/origin，不修改官方 submodule。
身份来源是项目已认可的匿名 client_id，不能据此识别真人。

## 固定设计

- 两组均从同一官方基座新训，不继承 r8 权重、优化器或学习率状态。
- `off` 与 `on` 具有完全相同的目标音频、文本、元数据与清单顺序；仅 `on` 保留可信 `ref_*`。
- 请求12小时目标音频，末尾最多去掉15行，使条数整除16，避免最后一步回绕到下一 epoch。
- 原 r8 权重：TH=FLEURS5/YODAS3/GS2 9，ID=FLEURS7/GS2 10。
  本轮 TH=FLEURS2/CV22配对3/YODAS3/GS2 9，ID=FLEURS4/CV22配对3/GS2 10；
  VI/TL/MS/ZH/EN 份额不变。CV22只取已有有效配对目标，不扩大或重新猜测身份。
- 两组共享无 ref 的验证清单。LoRA 64/64、dropout .05、lr1e-4、batch2×累积8、
  `enable_lm=true`、`enable_dit=true`、`enable_proj=false`，1 epoch，官方初始化 seed42。
- B 的 ref 时间属于额外条件输入，不算 target 配比；额外计算量不伪装成相同 FLOPs。
- 验收复用完整 v2 的182 case × seed42–46、CFG1.8、20步、禁重试。
  这些 seed 用于对齐历史 base/r8；本轮不宣称重新覆盖 +7 重试。
