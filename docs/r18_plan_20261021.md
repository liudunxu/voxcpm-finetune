# r18 计划：id 口音优先的加强轮（2026-10-21）

> 状态：**待用户批准**。批准前不启动下载/训练。

## 目标与判据

1. 总体 CER ≤ r13x 的 **0.0410**（v2 118case × 3seed，cfg1.8/20步/线上 fil ref，禁重试，同口径配对）
2. id/th/tl 任一语种相对 **base** 退化 >0.05 即不通过；相对 **r13x** 的 ΔCER 超出 ±0.01 噪声带需解释
3. SIM（WavLM X-vector）相对 base |Δ| ≤ 0.02
4. **id 口音（去 MY 腔）是本轮主目标**：终判门 = 印尼语母语者盲听（`work/audio_ab/20261020_id_prosody/` 包加进 r18 样本）；离线只做代理参考，不作门禁

## 数据方案（关键：id 量全部来自盘上已加工存量，无需新下载）

盘上已加工 id 存量 **21.8h**（r13x 只用了 4.49h）：fleurs_id 7.22h + gigaspeech2_id 7.38h + cv22_id 7.22h。
三者全是印尼本土来源（FLEURS CC-BY-4.0 / Gigaspeech2 Apache-2.0 / Common Voice CC0），许可链与 r13x 同样干净。

| 语种 | r13x | r18 计划 | 构成 |
|---|---|---|---|
| id | 4.49h (37.4%) | **~7h (~44%)** | fleurs_id 2h + gs2_id 3h + cv22_id 2h |
| th | 3.32h | 3.3h 不变 | 同 r13x（fleurs+gs2+cv22+yodas） |
| tl | 3.32h | 3.3h 不变 | fleurs_tl |
| zh | 0.59h | 0.8h (5%) | fleurs_zh 回放 |
| en | 0.29h | 0.4h (2.5%) | fleurs_en 回放 |
| **合计** | 12.01h | **~14.8h** | 预计 ~7600 条训练 |

- id 曝光量：7h × 3ep = **21h**，是 r13x（13.5h）的 1.6 倍
- 构建时新 id 行与 v2 验收集文本查重（撞文本的剔除，避免文本暴露污染对照）
- 固定验证集沿用各源 `holdout.json` 钉住的组，不重排

## 训练配置（与 r13x 完全一致，只改数据）

LoRA r=64/alpha=64/dropout=0.05，enable_lm+dit、proj 关；lr 1e-4；batch 2×累积8=等效 16；
**3 epoch ≈ 1400 步**（按 ~7600 条估，实际以 `.plan.json` 为准）；warmup ~10%；wd 0.01；clip 1.0；
max_batch_tokens 8192；save/valid 250；交付 latest。单卡 4090D，预计训练 **~3h**。

## 验收流程（训完自动接）

1. v2 118 × seed 42/43/44，3 分片并行（~1h）
2. id 探针（base 锚点 CER 0.059，r13x 水平待对照）
3. 三方对照表：base vs r13x vs r18，逐语种 CER/漏尾/SIM
4. 口音代理（实验性，不作门禁）：Whisper 强制 id vs 强制 ms 转写同一批 id 生成音频比 CER 方向；词汇判据（adalah/berarti=id，ialah/bermaksud=ms）扫生成文本
5. 更新母语盲听包（id 探针句 × base/r8/r13x/r18）

晋级 = 满足上方判据 1–3；口音结论等母语评审，不阻塞晋级，但晋級后 HF 卡上保持「口音待母语验证」标注。

## 不做的事

- 不用 Atika88 / thai_ser / 任何 ms 源
